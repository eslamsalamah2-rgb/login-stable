# Drop item templates

ضع صور العناصر التي تريد اختبار التعرف عليها هنا.

Recommended workflow:

1. Open a saved `raw_account...png` or `grid_account...png` from the debug logs.
2. Crop one item slot or the item icon clearly.
3. Save it in this folder as a PNG, for example:

```text
stone.png
gold.png
meteor.png
```

Current stage is probe-only: the program reads these templates and reports matching slots. It does not drop or click items yet.
